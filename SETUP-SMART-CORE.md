# AI-репетитор Софьи — SMART CORE

Этот пакет объединяет следующий большой этап разработки.

## Что добавлено

### Для Софьи
- восстановление последнего чата по предмету и режиму;
- кнопка «Новое занятие»;
- строгая лестница помощи;
- первая ошибка → самопроверка, а не мгновенная подсказка;
- постепенные уровни подсказок;
- сохранение реальных диалогов;
- оценка самостоятельности;
- слабые темы;
- живой прогресс на главной;
- реальная серия занятий;
- отдельная учебная скорость голоса для английского;
- выбор спокойного/доброжелательного характера голоса.

### Для родителя
- реальные показатели;
- история занятий;
- открытие полного диалога конкретного занятия;
- отдельный чат с Луником;
- обсуждение методики как с реальным репетитором;
- предложение нового правила из родительского чата;
- подтверждение родителем перед сохранением правила;
- ручное добавление/отключение правил.

## Важно

Базовые педагогические правила не заменяются родительскими. Родительские правила добавляются сверху.
Временные правила в этой версии помечаются как временные, но отключаются вручную — автоматический срок действия можно добавить позже.

## Установка — ускоренный вариант

### Шаг 1. Supabase

Откройте:

SQL Editor → New query

Откройте файл:

supabase/SMART-CORE.sql

Скопируйте весь код → Run.

Ожидаемый результат:

Success. No rows returned

### Шаг 2. Установка файлов

Распакуйте ZIP.

В папке пакета откройте PowerShell и выполните:

powershell -ExecutionPolicy Bypass -File .\INSTALL.ps1

Скрипт:
- сам скопирует файлы;
- сам заменит нужные версии;
- перед заменой создаст резервную копию в проекте.

Если проект лежит не в стандартном пути:

powershell -ExecutionPolicy Bypass -File .\INSTALL.ps1 -ProjectPath "ВАШ_ПУТЬ"

### Шаг 3. Перезапуск

В VS Code:

Ctrl + C

npm run dev

### Шаг 4. Проверка

1. Войти как родитель.
2. Главная `/` — нижний прогресс должен брать реальные данные.
3. Открыть математику → тренировку.
4. Написать «задай пример».
5. Ответить неправильно.
6. Луник должен сначала попросить проверить себя, а не сразу дать подсказку.
7. Уйти на другую страницу и вернуться — недавний чат должен восстановиться.
8. `/parent` — занятие должно появиться.
9. Нажать на занятие — откроется полный диалог.
10. В родительском чате написать:
   «Чаще хвали Софью, когда она сама находит правильный шаг».
11. Луник должен предложить сохранить правило.
12. Нажать «Сохранить правило».

## Что не требуется менять

`.env.local` остаётся прежним:
- YANDEX_API_KEY
- YANDEX_FOLDER_ID
- NEXT_PUBLIC_SUPABASE_URL
- NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY

## Резервная копия

INSTALL.ps1 создаёт папку вида:

_backup-smart-core-20261005-203000

Если что-то понадобится вернуть, исходные заменённые файлы находятся там.
