# Adaptive Core Hotfix v1.1

Исправляет три замечания после реального теста:

1. `Новое занятие` теперь видно внутри учебной карточки как sticky-кнопка.
2. Помощь больше не должна перескакивать сразу к полному решению.
3. Умножение в столбик получает строгий формат с выравниванием.

## Новая лестница помощи

- 0: только самопроверка, без числовой подсказки;
- 1: маленькая подсказка;
- 2: конкретная подсказка, но без полного решения;
- 3: один шаг вместе;
- 4: полный разбор.

Для visualBlock на уровнях 0–2 финальный ответ запрещён.

## Умножение в столбик

Полный вид, когда он уже разрешён:

     45
  ×  36
  -----
    270
   1350
  -----
   1620

До полного разбора строки должны оставаться пустыми:

     45
  ×  36
  -----
    ___
   ____
  -----
   ____

## Установка

Распакуйте папку в проект и выполните:

powershell -ExecutionPolicy Bypass -File .\INSTALL-HOTFIX.ps1

SQL не нужен.

После установки перезапустите:

npm run dev

И обязательно нажмите `＋ Новое занятие`, чтобы старое состояние помощи не смешивалось с тестом.
