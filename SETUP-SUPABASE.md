# Быстрый запуск Supabase-блока

1. В Supabase: SQL Editor → New query.
2. Откройте `supabase/schema.sql`, скопируйте целиком и нажмите Run.
3. Скопируйте содержимое этого архива в корень `ai-tutor-sofia`.
4. Разрешите замену:
   - app/parent/page.tsx
   - app/subject/[subject]/[mode]/page.tsx
5. Убедитесь, что `.env.local` содержит Yandex + Supabase строки.
6. Перезапустите `npm run dev`.
7. Откройте `http://localhost:3000/login`.
8. Зарегистрируйте родительский аккаунт.
9. После входа откройте `/parent`.
10. Проведите одно занятие — оно появится в родительском кабинете.

Важно: слабые темы и автоматическая оценка самостоятельности пока не вычисляются.
Сейчас сохраняются реальные занятия и сообщения. Следующим аналитическим блоком добавим
структурированную оценку прогресса.
