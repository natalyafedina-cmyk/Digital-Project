# Adaptive Learning Core v1

Это следующий большой блок AI-репетитора Софьи.

## Что меняется

### 1. Универсальная адаптивная логика для всех 8 предметов
Луник выбирает метод объяснения, а не использует один шаблон.

Поддерживаемые методы:
- визуальная схема;
- разобранный пример;
- пошаговый разбор;
- аналогия;
- игровой формат;
- диалог;
- вспоминание без подсказки;
- сравнение;
- устная практика;
- линия времени;
- причины и следствия;
- классификация;
- история/сюжет;
- эксперимент;
- географическая логика;
- анализ персонажей.

### 2. Предметная методика
Отдельные правила для:
- математики;
- физики;
- русского языка;
- английского языка;
- истории;
- географии;
- биологии;
- литературы.

### 3. Если метод не помог — Луник должен менять подход
После следующего ответа ребёнка система получает осторожный сигнал,
помог ли предыдущий метод.

Система не делает вывод по одной попытке.
Предпочтение считается хотя бы предварительным только после нескольких наблюдений.

### 4. Наглядные блоки
Для математики и других предметов Луник может вернуть отдельный visualBlock.

Например:

  27
× 18
----
 216
270
----
486

В интерфейсе такой блок показывается отдельно моноширинным шрифтом.

### 5. Enter
- Enter — отправить.
- Shift + Enter — новая строка.

Работает в учебном чате и родительском чате.

### 6. Реальные экраны предметов
`/subject/math`, `/subject/english` и остальные больше не должны показывать
демонстрационные "65%", "Past Simple 55%" и выдуманные последние занятия.

Блоки:
- Сейчас изучаем;
- Стоит повторить;
- Последние занятия;
- Реальный прогресс

берутся из Supabase. Если данных нет — интерфейс честно пишет,
что данных недостаточно.

### 7. Родительская адаптивная аналитика
Родитель видит:
- какие методы уже проверялись;
- сколько наблюдений;
- предварительный результат;
- подтверждённые слабые темы;
- уровень достаточности данных.

### 8. Родительский AI перестаёт придумывать прогресс
Ему передаются реальные:
- занятия;
- самостоятельность;
- слабые темы;
- статистика методов;
- активные правила.

Если данных мало, он обязан это сказать.

### 9. Предложение заменить правило
Если накоплены реальные основания и действующее правило похоже на
неэффективную стратегию, Луник может предложить заменить правило.
Самостоятельно он ничего не меняет.

# Установка

## Шаг 1 — SQL

Supabase → SQL Editor → New query.

Откройте:

`supabase/ADAPTIVE-CORE-v1.sql`

Скопируйте весь код и нажмите Run.

Ожидаемо:

`Success. No rows returned`

## Шаг 2 — установка файлов

Распакуйте архив.

Если папку пакета положили внутрь:

`C:\Users\PC\ai-tutor-sofia\ai-tutor-sofia-adaptive-core-v1`

то в терминале:

```powershell
cd C:\Users\PC\ai-tutor-sofia\ai-tutor-sofia-adaptive-core-v1
powershell -ExecutionPolicy Bypass -File .\INSTALL-ADAPTIVE.ps1
```

Установщик копирует файлы ПО ОДНОМУ и сам создаёт нужные папки.
Перед заменой создаётся резервная копия:

`_backup-adaptive-core-...`

## Шаг 3 — перезапуск

```powershell
cd C:\Users\PC\ai-tutor-sofia
npm run dev
```

Если порт 3000 занят старым процессом, сначала остановите старый сервер.

# Контрольная проверка

## Математика
1. Новое занятие.
2. Попросить пример на умножение.
3. Ошибиться.
4. Проверить: первая реакция — самопроверка, не готовая подсказка.
5. Написать: `покажи столбиком, не объясняй длинным текстом`.
6. Должен появиться отдельный визуальный блок.

## Enter
- Enter отправляет.
- Shift + Enter переносит строку.

## Смена метода
1. Написать `я не понимаю`.
2. Луник не должен повторять тот же способ длиннее.
3. Он должен попробовать другой формат.

## Экран предмета
Открыть `/subject/math`.
Никаких выдуманных тем и процентов.
Только реальные данные или сообщение `Пока недостаточно данных`.

## Родитель
Открыть `/parent`.
В блоке адаптивной аналитики сначала нормально увидеть:
`Пока только ранние наблюдения` или `Данных пока недостаточно`.

Спросить:
`Какой способ объяснения Софье подходит лучше?`

Если данных мало, Луник не должен придумывать ответ.

# Важно о персонализации

Adaptive Core v1 собирает наблюдаемые сигналы, но не ставит ребёнку "тип обучения".
Например, система может постепенно установить:
`визуальные схемы в математике сейчас дают лучший результат`,
но не должна утверждать:
`Софья — визуал`.

Это принципиально: методика должна оставаться гибкой и пересматриваться.
