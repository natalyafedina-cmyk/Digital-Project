## Педагогика
[ ] Первая ошибка → самопроверка.
[ ] Подсказка усиливается постепенно.
[ ] После "не понимаю" меняется способ объяснения.
[ ] Ответы по умолчанию короткие.
[ ] По просьбе "покажи" появляется visualBlock.

## Все предметы
[ ] Математика — схемы/столбики/примеры.
[ ] Физика — смысл + схема/эксперимент.
[ ] Русский — сравнение и разбор.
[ ] Английский — диалог/устная практика.
[ ] История — сюжет + причины/следствия.
[ ] География — связи место/климат/люди.
[ ] Биология — процессы/схемы/классификация.
[ ] Литература — герои/мотивы/обсуждение.

## Реальные данные
[ ] На экране предмета нет выдуманных процентов.
[ ] Слабые темы только из реальных данных.
[ ] Последние занятия реальные.
[ ] Родительская самостоятельность обновляется.

## Родительский AI
[ ] При малом количестве данных говорит, что данных мало.
[ ] Не придумывает интерес, мотивацию и успехи.
[ ] Новое правило предлагает сохранить.
[ ] Правило не меняется без подтверждения.
[ ] При наличии оснований может предложить заменить правило.

## Адаптация
[ ] После нескольких занятий появляются наблюдения по методам.
[ ] Методы с 1 наблюдением не называются доказанным предпочтением.
[ ] Неэффективный метод не должен повторяться автоматически.
